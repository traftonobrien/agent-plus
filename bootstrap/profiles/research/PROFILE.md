# Research Profile

## Required gates

1. Source provenance and population coverage.
2. Frozen target, temporal order, comparator, and metric contract.
3. Deterministic evaluation.
4. Fresh independent verification.
5. Claim-evidence register review.

## Required records

- Research contract.
- Source log.
- Evidence record.
- Independent review.
- Session handoff.

## Claim rule

Do not claim future prediction without chronological evaluation. Do not claim decision value or real-world impact without dedicated evidence.

## Lean R default

For R projects, use ordinary R and the existing project `renv`. Work one small chunk at a time,
parse the changed files, and run only the named focused tests. Add no package or subsystem unless an
observed requirement proves it is necessary.

For migrations, trace complete source behavior before claiming parity. Test the dominant operation
at representative volume, use vectorized table operations, and keep expensive cached stages
separate from cheap downstream targets. Retain failed attempts as evidence; use `$outcome-audit`
for prospective reliability measures instead of adding another tracker.

Before an expensive target run, inspect the exact dependency graph. Record which named targets are
current or outdated, run the smallest target that reaches the decision endpoint, and reuse current
expensive ancestors. A downstream reset is distinct only when graph evidence proves it cannot reach
an exhausted upstream interface.
