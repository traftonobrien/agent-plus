# Agent+ 0.4.1: Astra configuration and workflow tuning

Proposed release note. Publication requires a separate owner decision after candidate acceptance.

Updates Agent+ for Astra-selected Codex sessions with clearer model routing, complete startup
context, native skill discovery, and proportionate verification. Existing research, evidence,
and release controls remain in place. No general performance improvement is claimed.

## Changes

- Preserve the owner-selected model and reasoning effort; Astra/high is the tested baseline.
- Clarify routine work, formal engineering, independent review, and release responsibilities.
- Print complete current startup records and move superseded public state into explicit history.
- Provide twelve native project skills with unique metadata and complete regular-file mirrors.
- Keep canonical and bootstrap policies aligned and add focused startup and skill parity checks.
- Document separate host runtime setup and the limits of the policy comparisons.

The package does not install a shell CLI, rewrite global Codex configuration, or synchronize consumer
projects. Unrelated local citation changes are excluded from this patch. The public research example
retains its coverage block, and the release adds no scientific or predictive claim.
