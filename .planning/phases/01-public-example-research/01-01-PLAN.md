# 01-01: Synthetic Coverage Gate

## Objective

Test whether the public example has enough independently reconciled illustrative coverage to authorize a future synthetic evaluation.

## Necessity card

- **Decision:** Whether the example may proceed to a future evaluation plan.
- **Uncertainty:** Whether all 12 required illustrative partitions have independent inventory support.
- **Existing evidence:** The example manifest lists only 11 partitions and no independent receipt.
- **Minimum action:** Compare the expected partition list with the illustrative manifest and inventory receipt.
- **Unlock:** A fresh review only if reconciliation passes.
- **Stop condition:** A complete reconciliation or `BLOCK-COVERAGE-EXAMPLE`.
- **Repeat trigger:** A new reviewable inventory receipt.
- **Budget:** Tier 0, one deterministic comparison, two attempts maximum.

## Boundary

- Allowed inputs: `EX-CONTRACT-001 v1`, `example-manifest-v1`, and synthetic inventory metadata.
- Forbidden actions: Raw data access, model fitting, performance reporting, imputation, or claim promotion.
- Acceptance: The evaluator record lists expected, located, missing, and independently verified partitions.

## Decision branches

- If `PASS`: Create a new, separately reviewed evaluation plan.
- If `BLOCK`: Write a block record and handoff. Do not model.
