# Brain Sync

## Trigger

Use when verified project knowledge must move into an Obsidian Brain, or when a curated note needs an index update.

## Purpose

Preserve durable methods, sources, and decisions without copying raw sessions into the startup context.

## Required inputs

- Exact source artifact or verified evidence record.
- Target curated note and index location.
- Public or private classification.

## Allowed actions

- Extract durable decisions, methods, and source links.
- Update the named curated note and its backlinks.
- Record provenance and limitations.

## Required outputs

- Updated curated note or a no-change result.
- Source references.
- A short statement of what remains only in hot memory or archive.

## Acceptance checks

- Every new statement links to a source artifact.
- No raw transcript, secret, or private path enters public knowledge.
- Index and backlinks resolve.

## Handoff requirements

State the note changed, verification completed, next action, and restart reference.

## Explicit limits

Do not treat the Brain as live project state. Do not infer evidence from a transcript. Do not publish private project material.
