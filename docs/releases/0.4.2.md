# Agent+ 0.4.2

This patch repairs installation preservation, consumer discovery, failure recording, and control diagnostics.

## Changes

- Installation checks every staged control before writing. Existing destination files remain protected.
  Generated Python cache directories stay outside the installed controls.
- Interface discovery covers supported analytical source formats across the repository.
  Explicit smoke execution now binds command, current inputs, successful exit, and captured output.
- Repeated identical failure closeouts count once, including concurrent submissions.
- Doctor distinguishes structural checks from explicit startup readiness. Startup checks binding
  procedures and reports the working version, Git HEAD, and dirty state.
- Lifecycle status compares managed content hashes. Honest terminal BLOCK and NULL outcomes can close
  at the failure limit while continued repair remains prohibited.
- Malformed JSON values, encodings, excessive nesting, and oversized integers produce typed failures.
- Canonical CI runs public validation. The safety scan covers the Git publication text inventory.
- The control guarantee guide maps enforcement to regression tests. A prospective Astra task baseline
  records observations without claiming unmeasured performance gains.

## Compatibility and limits

This is a compatible patch on the 0.4 line. Existing ledgers remain readable. New failure records
include replay identities. Historical events without those identities cannot be retroactively deduplicated.
The default doctor success label is now AGENT_PLUS_STRUCTURE_PASS. Consumers that parse that output
must use the documented structural/readiness distinction.

The package does not authorize data access, scientific claims, release publication, or automatic
consumer upgrades. Lexical discovery and pattern scanning have documented limits. Performance gains
remain unmeasured. See [control guarantees](../control-guarantees.md) for exact boundaries.
