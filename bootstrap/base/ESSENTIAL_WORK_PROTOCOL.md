# Essential Work Protocol

Before new work, complete `.planning/templates/ESSENTIAL-TASK.md`.

The task must name a decision, uncertainty, existing evidence, minimum action, unlock, stop condition, repeat trigger, and budget.

If `PASS` and `BLOCK` produce the same next action, stop. The task has no decision value.

Reuse evidence while the claim, implementation, inputs, environment, and acceptance contract remain unchanged. A new session does not invalidate existing evidence.
