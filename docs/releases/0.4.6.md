# Agent+ 0.4.6

This patch protects project changes during initializer cleanup and prevents an older package
from downgrading an installed project.

- The initializer publishes directories without replacing existing destinations. Rollback
  checks the original entry identity, contents, permissions, ACLs, and extended attributes.
  Changed entries survive a later collision or handled interruption.
- On macOS, ACLs and extended attributes are read through native descriptor interfaces.
  Linux uses descriptor-based extended attributes, including POSIX ACL attributes.
- Both `status` and `upgrade` report `INSTALLED_NEWER` and exit 1 before changing a target
  that already has a newer version. Forward upgrades and same-version package repairs remain available.
- The sync skill explains the newer-install result and reports recovery instructions when a
  durable transaction journal exists.

Directory publication requires macOS `renameatx_np(RENAME_EXCL)` or Linux
`renameat2(RENAME_NOREPLACE)` with filesystem support. Unsupported operations fail closed.
Validation and independent review ran on macOS. Linux runtime behavior remains unverified.
A force kill or power loss can leave a partial installation. Cleanup cannot arbitrate a
simultaneous external change at the instant of removal.

See [setup and upgrade guidance](../bootstrap-a-baseball-project.md).
