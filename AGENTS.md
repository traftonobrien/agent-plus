# Agent+ Project Instructions

## Purpose

Use this repository to document a controlled AI-assisted baseball research workflow. It is a public example package, not a data or modeling repository.

`AI_WORKFLOW.md`, `AI_AGENT_OUTPUT_POLICY.md`, and `ESSENTIAL_WORK_PROTOCOL.md` are binding alongside this file.

## Stable rules

1. Start with a research contract before substantive analysis.
2. Use deterministic checks for counts, schemas, hashes, tests, and official metrics.
3. Give each model a bounded task, permitted inputs, stop condition, and acceptance check.
4. Keep maker, evaluator, verifier, and human decision roles separate.
5. Treat `PASS`, null result, and `BLOCK` as valid outcomes.
6. Never claim prediction, decision value, or operational impact without the matching evidence level.
7. Start with `scripts/ai-context.sh` and the exact planning artifact named by hot memory.
8. Use `.planning/STATE.md` to identify the active public phase. Do not skip dependencies.

## Public safety

Do not add raw baseball data, credentials, private paths, personal transcripts, proprietary artifacts, or unlicensed third-party material. Use sanitized examples. Label examples and placeholders clearly.

## Context layers

- `AGENTS.md` defines project-wide instructions.
- `CLAUDE.md` defines the Claude runtime profile.
- `.claude-memory.md` records changing, verified project state.
- An Obsidian Brain stores curated long-term knowledge.
- A handoff records one bounded task's restart state.

## Closeout

Update verified state only after proportionate checks. Record one next action, open limits, and an exact restart command. Do not use a chat transcript as the source of truth.
