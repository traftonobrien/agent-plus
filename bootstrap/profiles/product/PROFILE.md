# Product Profile

## Required gates

1. User decision and acceptance criteria.
2. Data contract and privacy classification.
3. Deterministic behavior checks.
4. Release review and rollback path.
5. Operational handoff.

## Required records

- Product requirement.
- Data contract.
- Acceptance record.
- Release checklist.
- Session handoff.

## Claim rule

Do not describe a feature as decision-improving or operationally effective without measured, appropriate evidence.
