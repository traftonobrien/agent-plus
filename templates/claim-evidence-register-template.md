# Claim-Evidence Register — Template

Update rows in the existing register. Several claims can reference the same evidence record when
its scope and evidence level support each claim. Do not create a file for each claim or copy the
evidence into the register.

| Claim ID | Proposed claim | Evidence level | Required evidence | Evidence record | Status | Public wording |

Do not publish a claim whose required evidence is absent or whose level exceeds the evidence record.
