# Agent+ 0.4.4

This compatible patch makes routine work easier to start and accepted work easier to reuse.

## Changes

- Direct owner requests cover the named action and necessary routine steps. Existing authorization continues within its scope. Ask about real unresolved decisions or restrictions, not another permission phrase.
- Start from the current task and accepted prior work. New discovery is for a genuinely new research question. Routine edits, lookups and restarts stay in their existing workflow.
- Keep one current handoff. Put the latest verified state and next action first. Source logs, contracts and manifests retain their own authority. Do not create a second lessons register.
- Reuse an admitted source record when its identity, purpose and current authority fit. Inspect relevant rows when authorized. Preserve unresolved holds and source-specific limits.
- Use readable R with an existing entry point. R Markdown is optional. Add a model only for a distinct research purpose. Use file hashes when identity is a real acceptance requirement, not as routine ceremony.
- Carry accepted corrections into the existing procedure. Keep skills as focused routes to their owners. Canonical/bootstrap guidance and public Codex skill mirrors stay aligned.
- Use proportionate checks. Preserve the required release, scientific and source boundaries. Correct one existing citation token across the protocol, attribution, validator and test.

## Compatibility and limits

No CLI, schema, dependency, managed set or lifecycle interface changes. Existing projects keep their own data rules and output guides. Public defaults do not transfer another task's authority or accepted result.

Routine maintenance does not require a formal research chain. Shared controls and release work retain their required checks and independent review. Frozen identity checks, source conditions, scientific controls and first-error rules remain intact.

Guidance is instruction, not technical enforcement of model behavior. Package tests do not measure writing quality or productivity. Scientific phase remains BLOCK-COVERAGE-EXAMPLE. Consumer upgrades are separate target-specific actions.
