# Agent+ 0.5.0 candidate

This owner-selected minor release consolidates compatible workflow and verification refinements
on published v0.4.9. It does not change scientific, source, live-action or publication authority.

- Treat worker models as preferences when no exact model is pinned. Preserve controller choice,
  explicit model requirements and existing attempt limits.
- Close completed tasks without inventing another action or repeating unchanged passing checks.
  Keep one current handoff and its installed skill mirror aligned.
- Run the existing pinned strict type, lint and package checks in pull-request CI. Public CI streams
  actionable diagnostics. Release verification keeps raw output private by default, with explicit
  opt-in tests covering the separation. The CI runner uses uv 0.11.28.
- Remove five unused or forwarding manager helpers. Add six registry CLI regressions and translate
  startup launch failures into clear CLI errors without changing permissions, using a shell fallback
  or hiding the startup command's exit status.
- Map supported commands and checking capabilities to existing tests in the architecture guide.
  Keep installer ownership, lifecycle locking, recovery and verifier isolation boundaries intact.

The combined local bundle passed strict mypy, Ruff and 248 package tests. Native synthetic task
and completed-resume trials passed. A fresh published v0.4.9 archive passed installation, doctor,
startup readiness and status without a Git checkout. These observations do not verify a future
archive, universal agent behavior, scientific validity or a Linux run of this candidate.

This is candidate documentation. Exact candidate verification and fresh independent review remain
separate evidence, and publication requires an explicit owner decision. No consumer update is included.
