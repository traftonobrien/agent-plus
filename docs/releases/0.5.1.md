# Agent+ 0.5.1 candidate

This patch fixes two compatibility defects on published v0.5.0.

- Lifecycle comparisons accept numeric major.minor.patch versions with valid optional +build
  metadata. Ordering uses the numeric release, while records retain the full label. Downgrades
  still fail before locks or writes. Malformed metadata and prerelease labels remain unsupported.
- Active-chain routing retains signed-64-bit cumulative failure counts, including counts above two.
  Two or more failures still require architecture reset for continuation. Honest BLOCK and NULL
  closeout remain available. Canonical and bootstrap guards use the same behavior.

Focused regressions reject the original defects. The reviewed seven-file patch passed strict type,
lint and 252 package tests. Exact release-candidate verification remains separate evidence.

Build metadata does not establish exact upstream synchronization. This patch does not merge local
policy customizations, reset failure history, or authorize publication or a consumer migration.
Scientific, source, review and release boundaries retain their scope.
